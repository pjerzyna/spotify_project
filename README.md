# Spotify Playlist Generator 🎵

## Project Overview 📌
Spotify Playlist Generator is an application that generates optimal playlists using a **simulated annealing algorithm** and a provided dataset. The application consists of a backend written in **Python** and a frontend built with modern web technologies.

## Features 🚀
✅ Generate playlists based on a given dataset
✅ Optimization algorithm utilizing **simulated annealing**
✅ User interface for managing playlists

## Project Structure 📂
```
SpotifyPlaylistGenerator/
│── app.py                  # Main backend application
│── dataset.csv             # Music dataset
│── frontend/               # User interface 
│── requirements.txt        # Python dependencies
│── simulated_annealing.py  # Optimization algorithm implementation
```

## Installation and Setup 🔧
### 1. Clone the repository
```bash
git clone https://github.com/YourRepo/SpotifyPlaylistGenerator.git
cd SpotifyPlaylistGenerator
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python app.py
```
